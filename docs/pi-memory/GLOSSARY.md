# Home Pi Memory

Persistent knowledge for independent personal projects, with project-owned and private knowledge kept separate.

## Language

**Project memory**:
Durable knowledge belonging to one project, useful across sessions and suitable for that project's sharing policy.
_Avoid_: Conversation history

**Private memory**:
Durable personal or machine-specific knowledge that is not intended to be shared through a project's repository.
_Avoid_: Secret store

**Handoff**:
A short account of unfinished work for a particular task. It is transient task state rather than durable project knowledge.
_Avoid_: Project memory
