# Retired Pi memory extension

Historical reference only; nothing in this directory is linked or loaded by Pi.

`extension/` is the former `pi/extensions/memory/` package, `docs/` its design and
validation notes, and `tests/` its test (it imports the old paths and is not part of
the active suite). Private notes it saved stay machine-local in `~/.pi/agent/memory/`.
Use BB memory or project docs instead.
