Historical reference only; nothing in this directory is linked or loaded by Pi.

BB use BB child threads. The former orchestration skill, four agent profiles,
Herdsman configuration and their old tests are preserved here unchanged.

machine-local; this archive contains configuration and instructions, not sessions.
