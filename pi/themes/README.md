# Terminal themes

`terminal.json` is vendored unchanged from
[pi-terminal-theme](https://github.com/mavam/pi-terminal-theme) v0.2.0 by mavam.
Upstream license: MIT.

Pi loads this as a standalone theme from `~/.pi/agent/themes/`, which `link.sh` links to
this folder; no package is required. Updates to this copy are manual.

`terminal` uses the standard ANSI palette.
